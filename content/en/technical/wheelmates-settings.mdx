## Start with a stable baseline

WheelMates is a two-player game, so a useful settings test must consider both frame rate and online stability. Begin at the display's native resolution, use a frame-rate limit your PC can sustain, and change one graphics option at a time. Test movement, camera response, and a busy cooperative puzzle before keeping a change.

Steam lists Windows 10 or 11, DirectX 12, and 15 GB of available storage for the PC version. Meeting those requirements does not guarantee a particular frame rate because the store page does not publish official per-preset performance targets.

## DLSS and display settings

Firevolt published an official demo update specifically naming **DLSS improvements** alongside connection-stability fixes. That confirms DLSS support in the PC settings, but it does not establish one universal best mode.

If DLSS is available on compatible hardware, start with the quality-oriented option and compare image clarity while the cars are moving. Use a more performance-focused mode only when the frame-rate benefit is necessary. Players without compatible hardware should use the game's available native-resolution or alternative scaling options rather than forcing unsupported settings.

Change V-Sync and frame limits deliberately. Community reports discuss interactions between DLSS and V-Sync, but those reports are not a complete official compatibility matrix. After every change, verify that the selected option remains applied after restarting the game.

## Controls and co-op consistency

RC-car handling is intentionally momentum-based. Before lowering graphics quality, distinguish a frame-time problem from normal steering behavior. Test with the same controller or keyboard setup, then adjust sensitivity only if that option is present in your current build.

For online sessions, both players should use the same game version. If one partner sees missing interactions or frequent disconnections, update the full game and Friend's Pass client before comparing graphics settings. A version mismatch is a separate issue from GPU performance.

## A repeatable tuning order

1. Update the GPU driver and WheelMates.
2. Verify native resolution and fullscreen mode.
3. Set a sustainable frame-rate target.
4. Test DLSS Quality on supported hardware.
5. Reduce expensive visual settings one at a time if needed.
6. Recheck a real two-player puzzle, not only the main menu.
7. Record the change that solved the problem so it can be reversed after a patch.

## FAQ

### Does WheelMates support DLSS?

Yes. An official Steam news post for the demo explicitly announced DLSS improvements.

### What are the best WheelMates settings?

There is no official universal preset. Native resolution, a stable frame-rate cap, and quality-oriented upscaling are sensible starting points.

### Can graphics settings fix online desync?

Not necessarily. Update both clients and confirm matching versions before treating a connection problem as a graphics problem.
