## Official WheelMates PC requirements

WheelMates requires a 64-bit Windows PC, DirectX 12, and 15 GB of available storage. The official Steam listing provides both minimum and recommended hardware tiers.

| Component | Minimum | Recommended |
|---|---|---|
| Operating system | 64-bit Windows 10/11 | 64-bit Windows 10/11 |
| Processor | Intel Core i5-8400 or AMD Ryzen 5 2600 | Intel Core i7-10700K or AMD Ryzen 7 3700X |
| Memory | 8 GB RAM | 16 GB RAM |
| Graphics | NVIDIA GTX 1060 or AMD RX 580 | NVIDIA RTX 3060 or AMD RX 6600 XT |
| DirectX | Version 12 | Version 12 |
| Storage | 15 GB available space | 15 GB available space |

The store does not attach an official resolution, graphics preset, or frame-rate target to either tier. “Recommended” therefore identifies a stronger configuration, not a guaranteed 60 FPS or specific visual setting.

## Requirements for two-player modes

WheelMates supports online co-op and shared or split-screen co-op. Local split-screen asks one PC to render two viewpoints, so it can be more demanding than an online session. If a minimum-spec PC struggles locally, lower the resolution or graphics settings and retest the same scene before changing several options at once.

For online Friend's Pass play, both computers must be able to run their installed client. The host meeting recommended specifications does not compensate for a guest machine below minimum requirements.

## Before buying or troubleshooting

1. Compare the exact CPU and GPU models, not only the brand names.
2. Confirm Windows is 64-bit and supports DirectX 12 with the installed driver.
3. Keep more than 15 GB free for installation and update headroom.
4. Update both the full game and Friend's Pass client.
5. Use Steam's refund and support information rather than third-party “can I run it” guarantees.

Laptop GPUs can perform differently from desktop cards with similar names. Steam lists model families but does not promise equivalence across every power limit.

## FAQ

Steam lists 15 GB of available space.

### Can WheelMates run with 8 GB RAM?

Yes, 8 GB is the listed minimum. The recommended tier lists 16 GB.

### Does WheelMates require DirectX 12?

Yes. DirectX 12 appears in both requirement tiers.
