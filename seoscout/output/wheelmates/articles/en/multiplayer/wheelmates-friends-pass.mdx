The WheelMates Friends Pass is a multiplayer feature that allows two players to experience the entire co-op driving adventure together while only requiring one person to own the full game. By downloading a specific version of the client, the second player can join a host's session for free, participating in every puzzle, mini-game, and story beat within Professor Everett Bloom’s house. This system supports the game's core design as a dedicated two-player experience, whether playing online or via local split-screen.

## How the Friends Pass Works

WheelMates is built specifically for two players, focusing on RC car exploration and physics-based puzzles. The Friends Pass ensures that the barrier to entry is low for "Player Two." While one player must purchase the full version of WheelMates, their partner only needs to download the "Friends Pass" version, which is available on the game's main store page. 

Notably, the Friends Pass version of the game was previously the game's demo. If a player already has the demo installed, it functions as the gateway to joining a full game hosted by a friend. This version does not allow a player to start a solo game or host others; it is strictly designed to act as a client for joining an existing owner's session.

## Step-by-Step Invite Guide

To successfully connect two players using the Friends Pass, both users must follow a specific sequence in the game menus. Ensure both players have a stable internet connection before beginning the process.

### Instructions for the Game Owner (Host)
1. Launch the full version of WheelMates.
2. From the main menu, select **Play**.
3. Choose **Play Online** and then select **Host**.
4. Look at the bottom right corner of the lobby screen to find the **Invite Code**.
5. Copy this code and send it to your friend.

### Instructions for the Friend (Guest)
1. Download and launch the **WheelMates Friends Pass** version.
2. From the main menu, select **Play**.
3. Select the **Friends Pass** option.
4. Enter the **Invite Code** provided by the host. Note that this code is case-sensitive.
5. Click **Join** to enter the host's lobby.

Once both players are in the lobby, the host can select a new game or load an existing save file to begin the adventure.

## Co-op Gameplay and Mechanics

In WheelMates, players control tiny RC cars navigating an oversized laboratory. The gameplay revolves around cooperation rather than combat. Players must use unique vehicular abilities to reach hidden corners of the house and solve environmental puzzles.

*   **Magnetic Wheels:** These allow the RC cars to drive onto walls and ceilings, reaching areas inaccessible to standard vehicles.
*   **The Rope:** Used to swing across large gaps or pull objects.
*   **Magnetic Grabber:** A tool for interacting with the environment and moving objects required for puzzles.
*   **Narrative Journal:** Both players contribute to a shared journal that tracks story fragments and clues regarding the disappearance of Professor Bloom.

The house acts as the primary challenge. While exploration is the main focus, players will also encounter mini-games designed to test driving skills and determine who is the better driver in a competitive setting.

## Technical Requirements and Troubleshooting

For the best experience when using the Friends Pass, players should ensure their software versions are identical. The developers at Firevolt Team frequently release hotfixes to address progression issues and synchronization bugs, such as the "Rope Swing" not appearing for the joining player.

To verify your version, look at the lower-left corner of the main menu. If the version numbers do not match, the guest may be unable to join the host's session. If connection issues persist, players are encouraged to restart the Steam client to trigger any pending updates.

WheelMates also supports local co-op via split-screen. If playing on the same computer, the Friends Pass is not required, as both players can play using the single full copy of the game on one machine.

## FAQ

### Does my friend need to buy WheelMates to play with me?
No. Only one player needs to own the full game. The second player can download the WheelMates Friends Pass version for free to join your online session.

### Is the Friends Pass available for split-screen play?
The Friends Pass is specifically for online co-op. For split-screen play, you only need the full version of the game and two controllers (or a keyboard and controller) on a single computer.

### Why is the invite code not working?
The invite code is case-sensitive. Ensure the joining player enters the code exactly as it appears on the host's screen. Additionally, check that both players are running the same version of the game, visible in the bottom left corner of the menu.

### Can the Friends Pass player host a game?
No. The Friends Pass version is only for joining a player who owns the full game. To host a session, you must purchase the full version of WheelMates.
