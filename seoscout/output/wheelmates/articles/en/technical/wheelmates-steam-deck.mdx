## Is WheelMates Steam Deck Verified?

No official **Steam Deck Verified** rating was visible in the sources reviewed for this page. WheelMates is a Windows PC game on Steam, and community compatibility reports are not the same as Valve certification. Treat Deck play as something to test on the current build rather than a guaranteed support claim.

A Steam Community report says the **Play Local** option was disabled when the game ran on Steam Deck. That is a useful warning for players planning docked couch co-op, but it is one community report and does not establish a permanent design rule for every update.

## Safe Steam Deck test checklist

1. Install the latest WheelMates and SteamOS updates.
2. Launch the game without third-party files or unsupported launch commands.
3. Confirm that both controllers are recognized in Steam Input.
4. Check whether Play Local is selectable before arranging a couch session.
5. Test an early driving section for frame pacing, text readability, and battery use.
6. For online play, make sure the owner and Friend's Pass player use matching game versions.

Avoid copying environment-variable workarounds from an isolated discussion unless Firevolt confirms them. Such changes can alter device detection or disable performance tuning, and the available evidence does not establish a supported configuration.

## Performance expectations

Steam's PC requirements list a GTX 1060 or RX 580-class minimum GPU, 8 GB of RAM, DirectX 12, and Windows 10 or 11. Those desktop requirements do not translate into an official Deck frame-rate target. Use the Deck performance overlay to measure the current build and reduce settings one at a time when necessary.

Local split-screen renders two views and may be more demanding than online co-op. If local play is unavailable in the current Deck build, use a supported Windows PC or wait for an official update rather than assuming a workaround is risk-free.
